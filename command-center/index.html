How to Use This Dashboard

Quick guide to the NFL, NBA, WNBA, NHL and MLB gamebook feeds.

Finding a game
  1. Select a league, or keep All leagues to search across sports.
  2. Search for a team or matchup.
  3. Use the team and game-status filters to narrow the results.
  4. Switch between League sections and Combined games to change the layout.

Select a report link on a game card to open the available document.

Refresh frequency

This page automatically refreshes its current feeds and archive data every 5 minutes while open.

Use Refresh to check current feeds immediately. Game-clock displays update about every 15 seconds. League monitoring and publication schedules are independent; refreshing this page does not force a new report to be published.

Last checked is your browser's latest feed check. Last monitor check shows the latest successful recorded check for each league. Paused leagues intentionally retain older feed updates.

Game and report statuses

NBA, WNBA and NHL current listings show yesterday, today and tomorrow, rotating at 3 AM Eastern. Games leaving this view remain searchable in the archive.

  • Scheduled: The game has not started.
  • Live: The game is in progress; information can change.
  • Final — awaiting report: The game is over, but the report has not yet been located.
  • Report available: A report link is available to open and inspect.

Report types vary by league and may include gamebooks, game summaries, event summaries or other official statistical documents.

Historical archive

Use the Historical Archive below the current listings to find older games. Search by team or matchup, and filter by league, season or report status.

Historical records are separate from current games; some older reports may be missing.

Important information
  • Official reports may appear some time after the final whistle or buzzer; there is no guaranteed publication time.
  • For exact statistics, open and consult the linked source document.
  • Live scores, game statuses and report availability may be delayed or incomplete.
  • This independent resource is unofficial and is not endorsed by Fanatics or any sports league.
